# R3 任务书：Obsidian 归档

> 本任务书交给 Codex 实现。完成后由 Claude 质检，逐条核对「验收标准」，通过才进入 R4。

## 目标

把 `data/summarized/<日期>.json`（R2 产物）写入 Obsidian 记忆库，产出三样：**单条新闻一个 note + 每日简报 + 索引 MOC**。这是记忆库的最终形态。

## 前置

- 输入：`data/summarized/<日期>.json`（每条含 Item 8 字段 + 分类字段 + summary/insight/key_points）。
- 记忆库根目录：`config.yaml` 的 `vault.news_dir` = `D:/知识库/仓库/新闻记忆库`（子目录名也从 config 的 `vault.*` 读）。

## 记忆库目录结构

```
新闻记忆库/
├── 00-索引/
│   ├── 公司索引.md
│   ├── 分类索引.md
│   └── 领域索引.md
├── 01-公司/
│   ├── OpenAI/                  # 按公司建子目录
│   ├── NVIDIA/
│   └── _行业动态/               # company 为空的条目归这里
├── 02-每日简报/
│   └── 2026-08-29.md
└── 03-原文存档/                 # R3 不做，留空
```

## 需要新增的文件

```
src/write/
├── note.py        # 单条 note 写入（含文件名清理 + frontmatter + body）
├── digest.py      # 每日简报生成
├── index.py       # 索引 MOC 生成（扫描 note frontmatter）
└── archive.py     # 主入口：python -m src.write.archive
```

## 单条 note 规范

**文件路径**：`01-公司/<公司1>/<published> <清理后标题>.md`
- 多公司取 `company[0]`；`company` 为空 → `01-公司/_行业动态/`。
- 文件名：`<published> <标题>`，标题清理非法字符 `\ / : * ? " < > |`（替换为 `-`）、折叠空白、截断到 60 字；若同名冲突追加 `-<id前6位>`。

**frontmatter**（YAML）：
```yaml
---
type: news
id: <md5>
title: "<标题>"
company: [<公司1>, <公司2>]      # 空则为 []
category: "<分类>"
segment: [<领域1>, <领域2>]      # 空则为 []
source: "<来源>"
url: "<原文链接>"
published: "<YYYY-MM-DD>"
importance: <1-5>
tags: [<category>, <segment...>, <company...>]   # 扁平化，空格替换为 -
---
```

**body**（Markdown）：
```markdown
## 内容概括

<summary>

## 内容总结 / 产业启示

<insight>

## 要点

- <key_point1>
- <key_point2>

## 原文

[查看原文](<url>)
```
`key_points` 为空时省略「## 要点」段。

## 每日简报 `02-每日简报/<日期>.md`

```markdown
# 每日简报 <日期>

> 共 <N> 条相关新闻

## <分类1>
- [[note文件名]] — <summary 前 30 字>

## <分类2>
...
```
按 `category` 分组，链接用 note 文件名（不含 `.md`）。

## 索引 MOC `00-索引/`（每次运行重新生成）

扫描 `01-公司/**/*.md` 的 frontmatter，按 `company` / `category` / `segment` 分组，生成三个索引文件。示例（公司索引）：
```markdown
# 公司索引

## OpenAI
- [[2026-08-29 OpenAI发布xxx]]
```
MOC 是「扫描全部 note 重新生成」，幂等；不依赖 Dataview 插件。

## 验收标准（质检逐条核对）

1. `python -m src.write.archive` 能跑，写入记忆库。
2. note 数量 == summarized 条数；frontmatter 字段齐全正确；`[[链接]]` 可跳转。
3. 文件名无非法字符、无重复。
4. 每日简报生成，按分类分组正确。
5. 索引 MOC 生成，分组与链接正确。
6. **幂等**：连续跑两次不产生重复 note、简报/索引不重复。
7. 只写 D 盘（vault 在 D:）；不硬编码路径（读 config 的 `vault.*`）。

## 明确不做

- 不写 `03-原文存档`（可留空目录）。
- 不做调度/定时（R4）。
- 不硬编码 vault 路径、不写 C 盘。
