# R5 任务书：Web 前端（FastAPI）

> 分三轮：R5-a 后端 → R5-b 前端页面 → R5-c 打磨。每轮独立验收，通过才进下一轮。

## 目标

做一个本地 Web 应用：点「刷新」触发流水线 → 前端显示新闻 → 自动归档 Obsidian；前端可切换模型 + 设置 key。

## 架构

```
浏览器（单页 HTML + 原生 JS）
      │  HTTP（127.0.0.1:8000）
      ▼
FastAPI 后端（src/web/）
      │  POST /refresh → 子进程跑 src.scheduler.run（R0–R4）
      │  GET /news     → 读 data/summarized/*.json
      │  GET/POST /settings → 读写 model + key
      ▼
现有流水线 → 自动写 Obsidian 记忆库
```

## 技术选型

- 后端：**FastAPI + uvicorn**（新增依赖，加进 requirements.txt）
- 前端：单 HTML + 原生 JS（零框架、零构建）
- 流水线：**子进程**跑（每次刷新重读 `.env`/`config.yaml`，改 key/模型即时生效；隔离崩溃；进度靠捕获输出）

## 目录

```
src/web/
├── __init__.py
├── app.py        # FastAPI 应用 + 路由
├── runner.py     # 子进程跑流水线 + 进度状态跟踪
└── settings.py   # 读写配置（model/base_url → config.yaml，key → .env）
static/
└── index.html    # 前端页面（R5-b 实现）
```

## R5-a：后端

**接口（4 + 1 占位）**

| 方法/路径 | 作用 |
|---|---|
| `GET /` | 占位（R5-a 返回简单 JSON，R5-b 换成前端页） |
| `POST /api/refresh` | 子进程跑流水线；已有任务在跑则返回 409；返回 `{task_id, status:"running"}` |
| `GET /api/status` | 返回进度 `{running, stage, output, exit_code}`，stage ∈ R0/R1/R2/R3 |
| `GET /api/news?date=YYYY-MM-DD` | 读 `data/summarized/<date>.json` 返回数组 |
| `GET /api/settings` | 返回 `{model, base_url, api_key}` |
| `POST /api/settings` | body `{model, base_url, api_key}` → 写 config.yaml / .env |

**runner.py 要点**
- 用 `subprocess.Popen([sys.executable, "-m", "src.scheduler.run"], cwd=项目根, stdout=PIPE, stderr=STDOUT, text=True, encoding="utf-8")`。
- 后台线程逐行读 stdout，append 到输出缓冲，并解析 `[R0]/[R1]/[R2]/[R3]/R4 summary` 等标记更新 stage。
- 全局只保留一个任务；刷新时若在跑返回 409。

**settings.py 要点**
- 读：model/base_url 从 `config.yaml`，key 从 `.env`（复用 `config_loader`）。
- 写：config.yaml 用**按行替换**（正则替换 `model:`、`base_url:` 两行，保留注释）；`.env` 写/替换 `DEEPSEEK_API_KEY=` 行。
- 不硬编码 key；只写 D 盘。

**requirements.txt 追加**：`fastapi`、`uvicorn`。

**R5-a 验收标准**
1. `pip install -r requirements.txt` 后 `python -m src.web.app` 能启动，`http://127.0.0.1:8000` 可访问，`/docs` 可打开。
2. `POST /api/refresh` 真触发流水线（子进程跑 R0–R4），不阻塞；重复调用返回 409。
3. `GET /api/status` 能返回进度与 stage。
4. `GET /api/news?date=2026-08-30` 返回当天新闻数组。
5. `GET/POST /api/settings` 能读写；POST 后 `config.yaml` 的 model/base_url 与 `.env` 的 key 确实变化。
6. 只写 D 盘；key 只进 `.env`，不进代码/日志。
